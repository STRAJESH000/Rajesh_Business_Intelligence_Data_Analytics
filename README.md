# RajeshPradhan Business Intelligence Data Analytics

## Overview
This project demonstrates a Business Intelligence and Data Analytics workflow based on the internship session.

**Core flow:** Data → Information → Insight → Decision → Action

## Analysis included
- Executive KPIs: Revenue, Orders, Customers, Average Order Value, Profit and Growth
- Monthly revenue trend
- Regional performance
- Product category performance
- Customer segment analysis
- Risk identification
- Opportunity identification
- Fact → Insight → Opportunity → Action storytelling
- AI analyst prompt for verified-data-based recommendations

## Files
- `RajeshPradhan_Business_Intelligence_Data_Analytics.ipynb` — complete project notebook
- `requirements.txt` — Python dependencies
- `RajeshPradhan_Business_Intelligence_Data_Analytics_Report.docx` — project documentation
- `README.md` — project overview and instructions

## Dataset
The notebook contains a self-contained sample sales dataset, so no external dataset file is required for the submission package.

## Tools
Python, Pandas, NumPy, Matplotlib and Jupyter Notebook.

## Note
The notebook is designed as a submission artifact. It follows the BI concepts shown in the training: KPIs, trends, drivers, risks, opportunities and actions.
